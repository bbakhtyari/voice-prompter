# تله‌پرامپتر صوتی فارسی

تله‌پرامپتر اندروید که متن را با صدای گوینده جلو می‌برد: کلمه‌هایی که می‌خوانی را
تشخیص می‌دهد و همان خط را روی خط خواندن نگه می‌دارد. تشخیص گفتار کاملاً آفلاین و
روی خود تبلت انجام می‌شود (Vosk، مدل فارسی).

## امکانات

- حالت **صدا**: متن دنبال صدای تو می‌آید؛ تند بخوانی تند می‌رود، مکث کنی می‌ایستد.
- حالت **دستی**: اسکرول با سرعت ثابت، مثل تله‌پرامپترهای معمولی.
- ریموت بلوتوث / پدال / کیبورد: پخش‌وتوقف، سرعت ±، یک خط عقب/جلو. در تنظیمات
  می‌شود هر کلید دلخواه را به هر کار وصل کرد.
- آینه‌ی افقی و عمودی برای شیشه‌ی تله‌پرامپتر، اندازه‌ی فونت، فاصله‌ی خط، حاشیه،
  جای خط خواندن؛ متن راست‌چین، وسط‌چین یا چپ‌چین.
- فونت وزیرمتن داخل برنامه است و هر فونت فارسی دیگری را می‌شود از فایل ttf/otf
  اضافه کرد.
- «اشتباه شد»: با یک کلید/پدال، یا به‌صورت خودکار (تیک در تنظیمات)، برنامه می‌ایستد
  و دو خط به عقب برمی‌گردد. تشخیص خودکار از روی کلمه‌هایی است که به متن نمی‌خورند،
  پس اشتباه‌های کوتاه را ممکن است نگیرد و گاهی هم بی‌دلیل برگردد؛ پدال مطمئن‌تر است.
- ظاهر تیره (زمینه‌ی مشکی، متن سفید).
- انتخاب میکروفون: پیش‌فرض دستگاه، میکروفون تبلت، یا هدست بلوتوث.
- با انگشت می‌شود متن را جابه‌جا کرد؛ برنامه از همان‌جا ادامه می‌دهد.

## گرفتن فایل نصبی (APK) از GitHub

1. این پوشه را در یک ریپازیتوری GitHub بگذار (شاخه‌ی `main`).
2. تب **Actions** را باز کن؛ ساخت خودکار شروع می‌شود و چند دقیقه طول می‌کشد.
3. بعد از تمام شدن، در بخش **Releases** فایل `VoicePrompterFa.apk` را دانلود و
   روی تبلت نصب کن.

مدل گفتار فارسی (`vosk-model-small-fa-0.42`، حدود ۵۰ مگابایت) موقع ساخت دانلود و
داخل APK گذاشته می‌شود. اگر دانلودش موقع ساخت شکست بخورد، برنامه در اولین اجرا
فایل zip مدل را از تو می‌خواهد (از https://alphacephei.com/vosk/models).

## ساخت با Android Studio

پروژه را باز کن و Run بزن. برای اینکه مدل داخل APK باشد، فایل zip مدل را با نام
`model-fa.zip` در `app/src/main/assets/` بگذار؛ وگرنه برنامه در اولین اجرا آن را
از تو می‌خواهد.

## نکته‌ها برای دقت بهتر

- متن را همان‌طور بنویس که می‌خوانی («می‌خوام» نه «می‌خواهم»). برنامه تفاوت‌های
  رایج را تحمل می‌کند ولی هرچه نزدیک‌تر، بهتر.
- عدد را با حروف بنویس («نوزده» نه «۱۹») و کلمه‌های انگلیسی را فارسی بنویس؛ مدل
  فارسی این‌ها را نمی‌شناسد و از رویشان رد می‌شود.
- گزینه‌ی «محدود کردن لغات به کلمه‌های متن» را هم روشن و هم خاموش امتحان کن.
- خط کم‌رنگ پایین صفحه نشان می‌دهد برنامه چه شنیده؛ برای عیب‌یابی مفید است.

## مجوزها

- موتور تشخیص گفتار: [Vosk](https://alphacephei.com/vosk/) (Apache 2.0)
- فونت: [Vazirmatn](https://github.com/rastikerdar/vazirmatn) (SIL OFL 1.1)

کلید امضای داخل `keystore/` فقط برای این است که نسخه‌های جدید روی نسخه‌ی قبلی
نصب شوند؛ برای انتشار عمومی کلید خودت را بساز.
